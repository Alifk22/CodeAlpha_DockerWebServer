A Web Server, Containerized.

A production-style static web server packaged into a single Docker image with nginx — reproducible, portable, and health-monitored. Built as part of the CodeAlpha DevOps Internship.

Served from an nginx container

🐳 Docker

One Dockerfile builds an immutable image. Run it anywhere the engine runs — no "works on my machine".

⚡ nginx

A lean, battle-tested web server on the official Alpine base image for a tiny footprint.

❤️ Healthcheck

A built-in HEALTHCHECK lets the orchestrator know the container is actually serving traffic.

🧩 Compose

A docker-compose.yml wires up ports, restart policy, and health into one command.

Container Lifecycle

The core commands that take this server from source to running container.

# Build the image
docker build -t codealpha-webserver .

# Run it (host 8080 -> container 80)
docker run -d --name webserver -p 8080:80 codealpha-webserver

# Or bring the whole stack up with Compose
docker compose up -d

# Inspect, watch, and stop
docker ps
docker logs webserver
docker stop webserver && docker rm webserver

Health & Monitoring

The container reports its own health; the host watches resource usage live.

# See the HEALTHCHECK verdict (healthy / unhealthy)
docker inspect --format '{{.State.Health.Status}}' webserver

# Live CPU / memory / network usage
docker stats webserver
